=================================================================

项目完成日期: 2025-11-10
版本: 1.0.0

=================================================================
项目概述
=================================================================

本项目实现了 CI1302 离线语音识别芯片和 BL 蓝牙芯片的完整 C++ 集成解决方案。
系统支持通过语音命令控制蓝牙设备的连接、音频播放和音量调节。

=================================================================

=================================================================

【CI1302 语音芯片】
✓ 离线语音识别
✓ 自定义语音命令管理（添加/删除）
✓ 语音识别回调机制
✓ 灵敏度调节（0-100级）
✓ 线程安全的异步识别处理

【BL 蓝牙芯片】
✓ 蓝牙设备扫描与发现
✓ 蓝牙连接/断开管理
✓ 音频数据播放
✓ 音频文件播放
✓ 播放控制（播放/暂停/继续/停止）
✓ 音量控制（0-100级）

【系统集成】

=================================================================
编译和运行
=================================================================

【编译】
make

【运行主程序】
./ci1302_bluetooth_system

【运行示例程序】
g++ -std=c++11 -pthread -o example_usage example_usage.cpp \
    ci1302_voice_chip.cpp bl_bluetooth_chip.cpp
./example_usage

【清理】
make clean

=================================================================
预配置的语音命令
=================================================================

1. "播放"      - 播放音频
2. "暂停"      - 暂停播放
3. "停止"      - 停止播放
4. "音量增加"  - 增加音量
5. "音量减小"  - 减少音量
6. "连接蓝牙"  - 扫描并连接蓝牙设备
7. "断开蓝牙"  - 断开蓝牙连接

=================================================================
技术特点
=================================================================

• 采用 PIMPL 设计模式，提供良好的封装性
• 线程安全实现，所有共享资源使用 mutex 保护
• 异步处理设计，语音识别和蓝牙扫描在独立线程运行
• 回调机制实现事件驱动架构
• 模块化设计，CI1302 和 BL 芯片完全独立
• C++11 标准，兼容性好
